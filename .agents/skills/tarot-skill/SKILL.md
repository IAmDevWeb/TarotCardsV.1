# SKILL: Tarot Knowledge (ทาโรต์)

วัตถุประสงค์
--
ไฟล์นี้เป็น SKILL สำหรับ AI เพื่อใช้เป็นแหล่งความรู้เชิงบริบทเมื่อทำงานกับข้อมูลและการอ่านไพ่ทาโรต์ ช่วยให้โมเดลสามารถให้ความหมายของไพ่ ประเมินผังการอ่าน แนะนำคำถาม และปฏิบัติตามแนวทางจริยธรรมได้อย่างสม่ำเสมอ

ขอบเขตความรู้ (สรุป)
--
- ประวัติสั้น ๆ ของทาโรต์
- โครงสร้างสำคัญ: Major Arcana, Minor Arcana (Suits: Wands, Cups, Swords, Pentacles) และ Court Cards
- ความหมายหลักของไพ่แต่ละใบ (upright / reversed) สรุปเป็นคำสำคัญ (keywords)
- รูปแบบการอ่านยอดนิยม: single-card, three-card, Celtic Cross, past-present-future, relationship spreads
- แนวทางการตีความ: การรวมความหมายกับบริบท, การอ่านแบบบูรณาการ, เทคนิครับรู้ความไม่แน่นอน
- กรอบจริยธรรม: ไม่ให้คำแนะนำทางการแพทย์/กฎหมาย/การเงินโดยตรง, เคารพความเป็นส่วนตัว

ประวัติย่อ
--
ทาโรต์มีต้นกำเนิดในยุโรปช่วงปลายกลางถึงต้นสมัยใหม่ (ประมาณศตวรรษที่ 15-18 ขึ้นอยู่กับแหล่ง) เดิมเป็นไพ่เล่น ต่อมาถูกใช้เป็นเครื่องมือเชิงสัญลักษณ์สำหรับการพยากรณ์และการสะท้อนตนเองโดยนักสำนักหลายกระแสในศตวรรษที่ 18-19

โครงสร้างสำคัญ
--
- Major Arcana (22 ใบ): สัญลักษณ์หลักของการเดินทางทางจิตวิญญาณและเหตุการณ์สำคัญในชีวิต (ตัวอย่าง: The Fool, The Magician, The High Priestess, The Empress, The Emperor, The Lovers, The Chariot, Strength, Hermit, Wheel of Fortune, Justice, Hanged Man, Death, Temperance, Devil, Tower, Star, Moon, Sun, Judgement, World)
- Minor Arcana (56 ใบ): แบ่งเป็น 4 ชุด (14 ใบต่อชุด) แต่ละชุดสะท้อนด้านชีวิตที่เฉพาะเจาะจง
  - Wands (ไม้): ความคิดริเริ่ม, ความหลงใหล, การกระทำ, พลังสร้างสรรค์
  - Cups (ถ้วย): อารมณ์, ความสัมพันธ์, ความรู้สึก, ความรัก
  - Swords (ดาบ): ความคิด, การสื่อสาร, การตัดสินใจ, ความขัดแย้ง
  - Pentacles (เหรียญ/ดิน): วัตถุ, การงาน, การเงิน, สุขภาพร่างกาย
- Court Cards: Page, Knight, Queen, King — สะท้อนบุคลิกภาพ, บทบาท, หรือพลังงานที่เข้ามาในสถานการณ์

แนวทางการตีความทั่วไป
--
- คำสำคัญ: ให้ใช้คำสั้น ๆ เป็น keyword เพื่อช่วยในการรวมความหมาย
- บริบทและตำแหน่ง: ความหมายของไพ่ขึ้นกับตำแหน่งในผัง (เช่นอดีต/ปัจจุบัน/อนาคต) และไพ่รอบข้าง
- Upright vs Reversed: หากระบบรวม reversed ให้ตีความเป็นเงื่อนไขผ่อนปรน (blockage, internalized energy, delay, inverted lesson)
- ระดับความแน่นอน: ระบุความไม่แน่นอนและอย่าฟันธง — ให้การอ่านเป็นแนวทาง ไม่ใช่คำตัดสินเด็ดขาด

คำแนะนำเชิงจริยธรรมและข้อจำกัด
--
- ห้ามให้คำแนะนำทางการแพทย์ กฎหมาย หรือการลงทุนเป็นคำแนะนำที่มีผลผูกพัน — แนะนำให้ปรึกษาผู้เชี่ยวชาญที่ได้รับอนุญาต
- เคารพความเป็นส่วนตัวของผู้ใช้: ขออนุญาตก่อนบันทึกหรือแชร์ข้อมูลการอ่าน
- แจ้งให้ผู้ใช้รู้ว่าเป็นการอ่านเชิงสัญลักษณ์ ไม่ใช่การพิสูจน์ทางวิทยาศาสตร์
- หลีกเลี่ยงการตีความที่กระตุ้นให้เกิดการทำร้ายตนเองหรือผู้อื่น; เสนอลิงก์/แหล่งช่วยเหลือหากมีสัญญาณความเสี่ยง

คำแปลเบื้องต้นของ Major Arcana (คำสำคัญสั้น ๆ — ให้ใช้เป็น reference)
--
1. The Fool — การเริ่มต้น, ความไร้เดียงสา, ความเป็นไปได้ใหม่
2. The Magician — ความสามารถ, ทรัพยากร, การริเริ่มใช้อำนาจ
3. The High Priestess — สัญชาตญาณ, ความลับ, สติปัญญาที่ซ่อนอยู่
4. The Empress — ความอุดมสมบูรณ์, ความรัก, การดูแล
5. The Emperor — อำนาจ, โครงสร้าง, ความรับผิดชอบ
6. The Hierophant — ประเพณี, การเรียนรู้, คำแนะนำจากสถาบัน
7. The Lovers — ความสัมพันธ์, ทางเลือก, ความสมานฉันท์
8. The Chariot — ความตั้งใจ, ชัยชนะ, การควบคุม
9. Strength — ความกล้า, ความนุ่มนวล, การเอาชนะภายใน
10. The Hermit — การค้นหาภายใน, การสังเกต, การแยกตัว
11. Wheel of Fortune — วงจร, โชคชะตา, การเปลี่ยนแปลง
12. Justice — ความเป็นธรรม, การตัดสิน, การรับผลการกระทำ
13. The Hanged Man — การมองโลกจากมุมใหม่, การเสียสละ, การพักชั่วคราว
14. Death — การเปลี่ยนผ่าน, การสิ้นสุดที่นำไปสู่การเริ่มต้นใหม่
15. Temperance — ความสมดุล, การผสาน, การเยียวยา
16. The Devil — ข้อจำกัด, การยึดติด, เงื่อนไขที่ยาก
17. The Tower — การล่มสลายทันที, ความจริงที่ช็อก, การเปลี่ยนแปลงแบบฉับพลัน
18. The Star — ความหวัง, การฟื้นฟู, แรงบันดาลใจ
19. The Moon — ความไม่แน่นอน, ความฝัน, ความกลัวที่ซ่อน
20. The Sun — ความชัดเจน, ความสำเร็จ, ความร่าเริง
21. Judgement — การตื่นรู้, การประเมินผล, การเรียกคืน
22. The World — การบรรลุผล, วัฏจักรสมบูรณ์, การเฉลิมฉลอง

หมายเหตุ: สำหรับแต่ละใบ สามารถขยายเป็นความหมายแบบเต็ม (upright/reversed, จิตวิทยา, เงื่อนไขเชิงสัญลักษณ์) เมื่อต้องการรายละเอียดเชิงลึก

ตัวอย่างสรุปสำหรับ Minor Arcana (keywords)
--
- Wands: เริ่มต้น, ความกระตือรือร้น, ความคิดริเริ่ม, พลังงานสร้างสรรค์
- Cups: ความสัมพันธ์, อารมณ์, ความรัก, การเชื่อมต่อ
- Swords: ปัญญา, ความขัดแย้ง, การตัดสินใจ, การสื่อสาร
- Pentacles: ทรัพยากร, งาน, การเงิน, ความมั่นคงกายภาพ

ผังการอ่านยอดนิยม (ตัวอย่างและคำอธิบายสั้น)
--
- Single-card: คำตอบตรง ๆ หรือคำแนะนำประจำวัน
- Three-card (Past-Present-Future หรือ Situation-Action-Outcome): ให้บริบทและการพัฒนาเหตุการณ์
- Celtic Cross (10 ใบ): วิเคราะห์เชิงลึก — ตำแหน่งทั่วไป: Heart of Matter, Crossing, Foundation, Past, Near Future, Self, Environment, Hopes/Fears, Outcome

รูปแบบการตอบของ AI (templates)
--
เมื่อผู้ใช้ขอการอ่าน ให้ AI ปฏิบัติตามโครงสร้างดังนี้:
1) ยืนยันขอบเขตและขออนุญาต (เช่น ขอให้ผู้ใช้ยืนยันว่าเข้าใจว่าเป็นการอ่านเชิงสัญลักษณ์)
2) ขอข้อมูลพื้นฐานถ้าจำเป็น (เช่น คำถามเฉพาะ จุดสนใจ หรือว่าจะอ่านแบบ reversed หรือไม่)
3) แสดงผลลัพธ์: ระบุแต่ละตำแหน่งของผัง, ไพ่ที่ออก, คำสำคัญ, ความหมายสั้น (upright/reversed), และการรวมความหมายโดยรวม
4) ให้คำแนะนำเพิ่มเติมที่เป็นกลางและปฏิบัติได้ เช่น จุดที่ควรไตร่ตรอง คำถามที่ควรถามตัวเอง ขั้นตอนถัดไป

ตัวอย่าง prompt สำหรับ AI
--
- "ช่วยอ่านไพ่ 3 ใบ (อดีต/ปัจจุบัน/อนาคต) สำหรับคำถาม: 'ฉันควรจะเปลี่ยนงานหรือไม่'" — ให้แจ้งว่าต้องการ reversed หรือไม่
- "อ่านไพ่สำหรับความสัมพันธ์ 5 ใบ (ความรู้สึกของฉัน / ความรู้สึกของเขา / อุปสรรค / คำแนะนำ / ผลลัพธ์)"

การเชื่อมโยงกับทรัพยากรภายในโปรเจ็กต์
--
- หากมีไฟล์รูปภาพไพ่ใน public/Cards-png หรือ public/Cards-jpg ให้ใช้เป็นแหล่งอ้างอิงภาพเมื่อส่งผลลัพธ์ (ระบุชื่อไฟล์ภาพหากมี)

ตัวอย่างการตอบ (ย่อ) — แบบ 3 ใบ
--
- ไพ่: The Fool (อดีต) — คีย์: การเริ่มต้น
- ไพ่: Two of Swords (ปัจจุบัน) — คีย์: ความลังเล, การตัดสินใจ
- ไพ่: Ace of Wands (อนาคต) — คีย์: โอกาสใหม่, แรงกระตุ้น

การประเมินคุณภาพการอ่าน
--
- แสดงระดับความแน่ใจ: (สูง/กลาง/ต่ำ) ตามจำนวนไพ่ที่สนับสนุนการตีความ
- หากความหมายขัดแย้ง ให้เสนอการอ่านต่อหรือการ์ดเสริมเพื่อชี้แจง

แนวทางปรับแต่งสำหรับผู้ใช้ขั้นสูง
--
- ให้ตัวเลือกการตีความเชิงจิตวิทยา (shadow work), การปฏิบัติด้านสเปิร์ชเชิงจิตวิญญาณ หรือการตีความเชิงปฏิบัติการ
- สนับสนุน metadata เช่น วันเดือนปีเกิดของผู้ถาม (เฉพาะถ้าผู้ใช้ยินยอม) เพื่อเชื่อมโยงกับแง่มุมโหราศาสตร์หากต้องการ

Data exports
--
- `/.agents/skills/tarot-skill/tarot_cards.schema.json` — canonical schema JSON (id, slug, arcana, suit, imagePath, tags, upright/reversed fields)
- `/.agents/skills/tarot-skill/tarot_cards.json` — original generated JSON (legacy format)
- `/.agents/skills/tarot-skill/tarot_cards.csv` — tabular CSV export for quick import into spreadsheets or databases

Regenerate from source
--
- To (re)generate the canonical schema JSON run the transformer script after updating `DETAILED.md`:

```bash
node scripts/generate_tarot_data.js && node scripts/transform_tarot_schema.js
```

- `scripts/generate_tarot_data.js` parses `DETAILED.md` and writes `tarot_cards.json` (legacy), then `scripts/transform_tarot_schema.js` converts it into `tarot_cards.schema.json` (schema-1.0).

Examples
--
- `examples/load-tarot-node.ts` — Node/TypeScript example to load `tarot_cards.schema.json` from the repo filesystem
- `examples/load-tarot-browser.ts` — Browser/TypeScript example to fetch the schema JSON from a served path
